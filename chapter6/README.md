## Task Sheet 1-2-9
**Animal Interface and Gorilla Class**

This program demonstrates the implementation of the `Animal` interface and a `Gorilla` class that adheres to its contract. The `Gorilla` class provides specific behaviors for feeding, grooming, and petting a gorilla, with cautionary and instructive comments included in the methods.

### Key Features:
- **Animal Interface**:
  - `feed(boolean timeToEat)`: Determines if it's time to feed the gorilla.
  - `groom()`: Describes the grooming process.
  - `pet()`: Advises caution when petting the gorilla.

- **Gorilla Class**:
  - Implements the `Animal` interface.
  - Includes specific behaviors:
    - **feed**: Prints "put gorilla food into cage" when feeding.
    - **groom**: Prints "lather, rinse, repeat" during grooming.
    - **pet**: Prints "pet at your own risk" to caution handlers.
